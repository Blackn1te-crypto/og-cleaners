## 🌟 Overview

OG is a two-in-one brand — professional cleaning services and a Christian clothing line (hoodies, jackets, limited drops). This website is a fully self-contained, static site with a **built-in live settings panel** that lets you change themes, backgrounds, images, prices, welcome text, announcements, and contact info — all without touching code.

No backend. No database. No build tools. Just HTML, CSS, and vanilla JavaScript.

---

## ✨ Features

| Feature | Description |
|---|---|
| 🎨 **6 Accent Themes** | OG Green · Midnight · Royal · Sunset · Christian · Ocean |
| 🌈 **6 Background Presets** | Deep Space · Royal Night · Forest · Sunset Glow · Ocean Deep · Plum Rose |
| 🎛️ **Custom Colour Pickers** | Pick your own background gradient + accent + brand colours |
| 🖼️ **Tap-to-Edit Images** | Tap any image → choose new one from gallery → saves instantly |
| 💰 **Editable Prices** | Change hoodie prices from the settings panel |
| ✍️ **Editable Welcome Message** | Update the homepage hero text live |
| 📣 **Announcements Bar** | Show custom announcements on the homepage |
| 📧 **Editable Contact** | Business email and WhatsApp number, changeable in settings |
| 💾 **Persistent Settings** | Everything saves to your browser's localStorage |
| 📱 **Fully Responsive** | Mobile, tablet, desktop — perfect on every screen |
| ⚡ **Loading Splash** | Cinematic animated splash with rotating messages |
| 🔗 **Direct WhatsApp Order** | Every hoodie has an "Order" button that opens WhatsApp pre-filled |
